# Changelog

## 1.0.0
* One installer for Revit 2024–2027: dialog triangles (native add-in) and Project Browser triangles.
* Automatic per-version compatibility checks; unsupported versions are skipped with a reason.
* Verified backups, atomic writes, exact-reversal restore, emergency restore tool.
* Migration of the experimental EKGlyph / EKTreeGlyphProbe2024 add-in.
