EK Triangle
===========

Replaces Revit's "+" / "-" expand/collapse symbols with small dark-gray
triangles (right = collapsed, down = expanded) in:
  * Revit dialogs such as Visibility/Graphics (Revit add-in), and
  * the Project Browser (views and sheets).

Turn the dialog triangles off without uninstalling:
  open glyph.ini in this folder, set Enabled=0, restart Revit.

Remove everything:
  Windows Settings > Apps > Installed apps > EK Triangle > Uninstall.

Emergency restore (also works if Revit does not start):
  Start menu > EK Triangle Restore, or run
  C:\ProgramData\EKTriangle\EK Triangle Restore.exe

Logs: %LOCALAPPDATA%\EKTriangle\Logs and C:\ProgramData\EKTriangle\Logs
