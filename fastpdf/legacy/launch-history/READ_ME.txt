EK FASTPDF — ONE-CLICK LAUNCH HELPER

This helper does NOT reinstall or modify your PDF viewer. It starts the
existing EXE using the direct Windows method that worked in the prior diagnostic.

1. Extract BOTH START_EK_FASTPDF.cmd and START_EK_FASTPDF.ps1 into the new
   v1.1 project folder (the one that contains BUILD_WINDOWS.cmd) OR into the
   v1.1 "EK FastPDF" output folder (where EKFastPDF.exe is located).
2. Double-click START_EK_FASTPDF.cmd.
3. If it works, use that launcher for now. Do not delete the other EXE/DLL files.
4. If it fails, send EKFastPDF_Start_Log.txt from the Desktop.

This helper changes no Windows security settings, permissions, or registry keys.
