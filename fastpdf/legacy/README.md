# Legacy reference (not built)

* `v1.1-source/` – the EK FastPDF 1.1 source as handed over, kept for before/after comparison.
  Its rendering path is reproduced faithfully in `tools/EKFastPDF.Bench/LegacyEngine.cs` for the
  "v1.1" rows of the engine benchmark.
* `launch-history/` – the diagnostic and launcher scripts used while investigating the v1.0/v1.1
  start-up error. EK FastPDF 1.2 does **not** need them; see `docs/LAUNCH-INVESTIGATION.md`.
